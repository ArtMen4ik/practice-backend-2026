### Быстрый запуск локально

1. Установить зависимости: `npm install`
2. Настроить `.env`:

```env
PORT=3000
JWT_SECRET=supersecret
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/booking_db
```

3. Применить миграции: `npx prisma migrate deploy`
4. Заполнить тестовыми данными: `node prisma/seed.js`
5. Запустить приложение: `npm start`

### Запуск в Docker

1. Выполнить `docker-compose up --build`
2. Дождаться запуска `db` и `app`
3. Открыть Swagger: `http://localhost:3000/docs`

## 📌 Предметная область

Сервис бронирования фотосессий у фотографа на конкретную дату и временной интервал.

---

## 🎯 Что бронируем

**Фотосессию у фотографа** на выбранную дату и время.

---

## 🧱 Основные сущности

- **User** — пользователь системы (CLIENT / PHOTOGRAPHER / ADMIN)
- **PhotographerProfile** — профиль фотографа (ресурс, который бронируют)
- **Service** — услуга (портретная, семейная и т.п.), длительность и цена
- **Booking** — бронь на временной интервал со статусом
- **Review** — отзыв клиента после завершённого бронирования

---

## ⚠️ Критичные ограничения

- Нельзя создать бронь, если интервалы времени пересекаются у одного и того же фотографа (если существующая бронь не отменена).
- Отзыв можно оставить только после завершения бронирования (`COMPLETED`).
- Доступ к данным ограничен ролями:
  - Клиент видит только свои бронирования
  - Фотограф видит бронирования по себе
  - Администратор видит всё

---

# 👥 Роли и права

В системе предусмотрено 3 роли:

| Роль             | Описание                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------- |
| **ADMIN**        | Полный доступ: управление пользователями, профилями, услугами, бронированиями и отзывами |
| **PHOTOGRAPHER** | Управляет своим профилем и услугами, видит свои бронирования                             |
| **CLIENT**       | Создаёт и отменяет свои бронирования, оставляет отзывы                                   |

---

# 🔄 Статусы бронирования

## Booking.status

- `PENDING` — создано, ожидает выполнения
- `CANCELLED` — отменено
- `COMPLETED` — завершено

### ✅ Разрешённые переходы

- `PENDING → CANCELLED` (клиент / админ)
- `PENDING → COMPLETED` (система по времени или админ)

### ❌ Запрещённые переходы

- Любые переходы из `CANCELLED`
- Любые переходы из `COMPLETED`

---

## 🚨 Возможные ошибки

- `409 TIME_CONFLICT` — пересечение интервалов бронирования
- `400 VALIDATION_ERROR` — нарушение бизнес-правил (длительность < 1, startAt в прошлом и т.д.)
- `403 FORBIDDEN` — доступ к чужому бронированию

---

## ✅ Разрешённые переходы

- `PENDING → CONFIRMED` (фотограф / админ)
- `PENDING → CANCELLED` (клиент / админ)
- `CONFIRMED → CANCELLED` (клиент / фотограф / админ)
- `CONFIRMED → COMPLETED` (система по времени или админ вручную)

---

## ❌ Запрещённые переходы

- Любые переходы из `CANCELLED`
- Любые переходы из `COMPLETED`

### Создание бронирования

**Входные данные:**

```
{
  "photographerId": "uuid",
  "startAt": "ISO datetime",
  "durationHours": 1
}
```

**Бизнес-ограничения:**

- Минимальная длительность — 1 час
- Только целые часы (1, 2, 3 и т.д.)
- startAt должен быть в будущем
- Нельзя создать бронь при пересечении интервалов
